# GreenTech Solutions - ICT 280 Final Project

## Project Description
GreenTech Solutions is a responsive and accessible website created for the ICT 280 Final Project. The website was designed for a fictional environmental technology company that helps businesses adopt sustainable and eco-friendly technology solutions.

The website provides information about the company, its services, sustainability resources, and contact information through a modern multi-page design.
